Tutorial 9Router

API Gratis → 9Router → AI Coding

Ikuti stepper ini. Ambil beberapa akses AI gratis, satukan lewat 9Router, lalu arahkan tool coding ke satu endpoint.

1

Ambil akses AI gratis

Mulai dari yang paling mudah. User boleh pilih chat tanpa API, atau API key untuk dipakai di coding tool.

🔑
API Key GratisAmbil key dari Groq, Gemini, OpenRouter, NVIDIA NIM, Mistral, Cloudflare AI, dan provider lain di Database.
💬
Chat GratisKalau belum siap konfigurasi, pakai jalur chat dulu. Tidak perlu endpoint, tidak perlu coding.
🏆
Pilih model yang masuk akalGunakan Ranking untuk memilih model coding/chat paling kuat, lalu cek status provider.
Buka DatabaseLihat RankingCek API Key
2

Sambungkan ke 9Router

9Router jadi pintu tunggal. Semua provider masuk ke satu dashboard, semua tool memakai satu Base URL.

📦
Install 9RouterButuh Node.js. Install sekali secara global, lalu jalankan server lokal.
npm install -g 9router
9router
🖥️
Buka dashboard lokalMasukkan API key dari langkah pertama ke menu Providers.
http://localhost:20128/dashboard
🔌
Base URL untuk semua toolGunakan endpoint OpenAI-compatible ini di Claude Code, Cline, ZCode, Cursor, Codex, atau tool lain.
http://localhost:20128/v1
Ganti password default dashboard. Jangan bagikan dashboard lokal, token, API key, atau file konfigurasi ke orang lain.
3

Hubungkan platform coding

Pilih tool. Masukkan Base URL 9Router, pilih model, lalu mulai coding. Kalau provider limit, pindah via 9Router.

🧩
VS Code + ClineJalur paling mudah. Provider: OpenAI-compatible. Base URL: 9Router. API key: isi sesuai konfigurasi 9Router.
♟️
ZCode / OpenCode / CodexTool CLI memakai endpoint yang sama. Cocok untuk coding agent.
🧗
Claude Code / Cursor / TraeGunakan mode OpenAI-compatible bila tersedia, atau ikuti tutorial spesifik tool.
Buka OnboardingTutorial Tool Lain

✅ Selesai

Sekarang workflow kamu: provider gratis sebagai bahan bakar, 9Router sebagai pintu tunggal, AI agent sebagai mesin coding.

“Unlimited” berarti workflow bisa berpindah provider saat kuota habis. Bukan janji setiap provider memberi kuota tanpa batas.
